| --- | --- | --- |
| IM Fell English (regular, italic) | Igino Marini, via Google Fonts (latin subset) | SIL OFL 1.1, `public/fonts/OFL-im-fell-english.txt` |
| Alegreya Sans (400, 500, 700) | Huerta Tipográfica, via Google Fonts (latin subset) | SIL OFL 1.1, `public/fonts/OFL-alegreya-sans.txt` |
| Alegreya Sans SC (500, 700) | Huerta Tipográfica, via Google Fonts (latin subset) | SIL OFL 1.1, `public/fonts/OFL-alegreya-sans-sc.txt` |
| Icons | Drawn for this card (`src/lib/ui/icons.ts`) | Original |
| Demo text: Oslo, the broken crane, the Mano Gris, the choices | Written for this card (`src/design/demo-data.ts`) | Original |
| Place names (Waterdeep, Puerto Profundo, Ciudad de los Muertos…) | D&D setting names used as campaign references | Used as names only; the descriptions are original |
| Character names and stats | Written for this card; not taken from any rulebook or character sheet | Original |

Fonts are served from `public/fonts/`; the app makes no request to Google at runtime. The OFL
allows bundling and redistribution with the licence text, which ships next to the files.

No illustration, map image or texture from an external source is used. The 3D textures in D11
are generated procedurally in code.
