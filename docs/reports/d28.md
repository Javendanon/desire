one row per ID; a higher revision replaces it in place, edition unchanged, and every existing
reference (`Condition`, `CharacterSpell`, `ActorConcentration`, `class_entry_id`,
`feature_entry_id`) selects ID/edition and reads current text. Git holds editorial history.
Map versions keep ID/revision pinning.
