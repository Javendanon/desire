## What changed

Read-only import of the single Nivel20 read that D06 confirmed
(`GET /games/dnd-5/campaigns/<id>-<slug>` with `Accept: application/json`). No other
endpoint, no HTML parsing, no write request.

- `crates/api/src/nivel20/mod.rs` — `Nivel20Client`: one explicit read per call, no retry,
  no polling, redirects disabled, 8 s global timeout, 200 KB body cap, `Accept` JSON only.
  `Nivel20Error` and the pure `compare` function that decides `new` / `unchanged` /
  `changed` and the changed field list.
- `crates/api/src/nivel20/path.rs` — `CampaignPath` / `parse_path`: only the browser path is
  accepted; absolute URLs, queries, fragments, traversal, non-numeric or zero-padded ids are
  rejected before any I/O.
- `crates/api/src/nivel20/metadata.rs` — `CampaignMetadata` DTO: unknown fields ignored,
  `name` required and bounded, description bounded, and an `id` that differs from the path is
  rejected so a response is never mapped onto another campaign.
- `crates/api/src/routes/nivel20.rs` — `GET .../nivel20` (local snapshot),
  `POST .../nivel20/preview` (read + report, writes nothing),
  `POST .../nivel20/import` (read + store when new or changed). DM-only, non-members get 404.
- `crates/api/src/store/nivel20.rs` — authorization, snapshot encode/decode, no SQL.
- `crates/persistence/src/nivel20.rs`, `migrations/0012_nivel20_imports.sql` —
  `campaign.nivel20_campaigns`: local campaign PK, unique `external_id`, `source_path`,
  `external_updated_at`, `jsonb` snapshot, `imported_at`.
- `crates/api/src/error.rs` — five source-error constructors (`source_requires_session`,
  `source_unavailable`, `source_rate_limited`, `source_rejected`, `source_not_found`).
- `crates/api/src/lib.rs`, `main.rs`, `payloads.rs`, `routes/mod.rs`, `store/mod.rs`,
  `crates/persistence/src/{lib,migrations}.rs`, `Cargo.toml`s — wiring, `NIVEL20_BASE_URL`
  at startup, request payload, module registration, `ureq =3.5.1` (rustls, no cookie jar).
- `crates/api/tests/nivel20.rs` — 9 integration tests against real migrations, real
  PostgreSQL and a local fake source.
- `docs/api/nivel20.md` — contract, mapping, change detection, session/CSRF policy, source
  failure table, sanitized example, known gaps. `docs/api/campaigns.md` now links to it
  instead of claiming Nivel20 is untouched.

## RED → implementation

The new failure classification was written as a failing test first: a 360 KB synthetic body
returned 503 `source_unavailable`, which is wrong (the source answered; the payload is
unusable). RED run: `an_oversized_source_body_is_rejected_as_a_payload_error` failed with
`left: 503, right: 502`. Fix: `http_error` maps `HttpError::BodyExceedsLimit` and
`HttpError::Protocol` to `Nivel20Error::InvalidPayload` (`crates/api/src/nivel20/mod.rs`),
so the response is 502 `source_rejected`. Same test then passed.

While reviewing, `crates/api/src/routes/nivel20.rs:83 save` had **5 parameters** (F2 floor
4). The gate did not report it — see the coverage note below — so it was measured directly
with `km smells ... --max-params 3`. Fixed by a `Target` struct holding state, caller,
campaign id and source; `save`, `previous`, `read_source` and `report` now take ≤ 3.

## Gate coverage and blockers (not green anywhere it was not run)

- **`cargo clippy` cannot run in this environment**: every crate fails in dependencies with
  `E0514 found crate serde compiled by an incompatible version of rustc`, with the same
  rustc/clippy version strings. Reproduced on a throwaway crate outside this repository, so
  it is a Homebrew toolchain problem, not this branch. CI runs clippy with the rustup
  toolchain pinned in `rust-toolchain.toml`. **Clippy is unverified here**; it must be
  confirmed on CI before merge.
- **The gate's `km smells` scope misses files**: with the gate's own flags
  (`km smells . --include-ext rs ... --max-params 3`) `crates/api/src/routes/nivel20.rs` is
  not reported at all, while `km smells crates/api/src/routes/nivel20.rs --max-params 3`
  reports it (and did report the 5-parameter `save`). So "0 floor blocks" does not cover
  deep Rust files: the changed files were measured individually, as above. This is
  pre-existing tool behaviour; fixing `tools/quality` was out of this card's scope.
- **Independent advisor: pending.** The workflow requires an advisor that did not write the
  code for changes over 50 lines. No second agent was available in this session, so the
  review below is a self-review and does not satisfy that gate. The card is not fully
  closed until an independent reviewer reads the diff.
- Not run (not touched): frontend checks, browser regressions, asset pipeline tests and the
  3D/map verifiers. No `.ts`/`.svelte` file changed.
